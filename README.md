# Cadence

Cadence is a simple iPhone app for logging workouts and runs.

Add sets during a workout, record runs, keep an eye on personal records, and view progress over time. It works offline and can also sync with the companion API.

## Features

- Strength workouts and runs
- Personal-record tracking
- Progress charts
- Local storage and optional sync

## Run it

Open `Cadence.xcodeproj` in Xcode 16 or later and run it on an iPhone simulator or device.

To build and run the tests from the command line:

```bash
swift build
swift test
```
